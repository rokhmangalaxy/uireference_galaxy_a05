# Folder ROM

Taruh ROM NES **milik Anda sendiri** di sini (mis. `roms/gun-nac-usa.nes`),
lalu jalankan `npm run build`. Build menyalinnya ke `dist/roms/`, dan aplikasi
bisa memuatnya lewat menu "Import ROM" (file tetap di perangkat Anda).

Folder ini **tidak** berisi game: hanya ROM uji buatan sendiri (legal) dan
README ini.

> Gun Nac © 1990 Compile / 1991 ASCII. ROM komersial tidak boleh
> didistribusikan. Dump hanya cartridge yang Anda miliki.
